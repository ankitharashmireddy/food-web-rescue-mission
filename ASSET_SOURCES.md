# Asset Sources

This project runs offline and does not use external runtime image, audio or font dependencies.

- Diagrams and icons: original SVG files created for this project.
- Organism visuals: original emoji/SVG-style canvas rendering and CSS art.
- Backgrounds and UI panels: CSS gradients and local SVG/CSS effects.
- Audio: generated with the Web Audio API in `js/app.js`.
- Fonts: standard system fonts.
- Inspiration PNGs in `assets/inspiration/` are reference material only and are not loaded by the game.

# Fonts

No font files are shipped. The site uses standard system fonts through CSS variables:

- `--font`: Segoe UI, system-ui, -apple-system, BlinkMacSystemFont, Roboto, Arial, sans-serif
- `--mono`: Cascadia Code, Consolas, SFMono-Regular, monospace

If custom WOFF2 files are added later, update `--font` and `--mono` in `styles.css`.

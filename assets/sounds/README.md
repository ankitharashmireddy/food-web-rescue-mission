# Sounds

No audio files are shipped. All sound effects are generated in the browser with the Web Audio API (`app.js`). This keeps the site offline and avoids binary assets.

Mapping:
- click.mp3 -> short square click
- correct.mp3 -> three-note rising chime
- incorrect.mp3 -> two-note falling sawtooth
- mission-complete.mp3 -> completion fanfare
- badge-unlock.mp3 -> completion chime
- victory.mp3 -> final results chime
